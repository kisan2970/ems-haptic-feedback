# 브레드보드 꽂는 위치 목록 (830홀, ESP32, 2채널 v2) — 만능기판 연결판 (출력부를 만능기판으로 옮긴 뒤, 간소화판 기준)

그림: [breadboard_830_esp32.png](breadboard_830_esp32.png). 열 번호 1~63, 행 a~j. 위쪽 레일은 바깥쪽 빨강 줄이 +3V3, 안쪽 파랑 줄이 GND. 아래쪽은 안쪽 파랑이 GND, 바깥쪽 빨강이 +3V3.

레일 구멍은 5개씩 묶여 있고 7·13·19·25·31·37·43·49·55·61열 자리는 비어 있다.

## Uno에서 ESP32로 옮기는 순서

1. 조건: Uno에서 ladder_test.py 통과 (강도 3 → 0으로 LED가 어두워짐). 그 전에는 옮기지 않는다.
2. Uno 선을 모두 뽑는다. 위 + 레일은 5 V가 아니라 ESP32 3V3에 꽂는다 (확장보드 V 점퍼가 3.3 V인지 확인).
3. 게이팅용 330Ω(g12~g16, g42~g46)을 150Ω으로 바꾼다. 555 · Q1~Q4 · 타이밍 부품은 그대로.
4. G32 → a3, G17 → j8, G16 → g28 / G33 → e33, G19 → j38, G18 → g58 / G27 → 아래 − 레일 32열.
5. 만능기판 H2: G23 → LA1, G4 → LB1, G13 → LA2, G14 → LB2, GND.  IMU: 3V3, GND, G21(SDA), G22(SCL).
6. ESP32 펌웨어 업로드 → board_check.py → LED 부하로 ssr_blink.py, ladder_test.py를 다시 통과.
7. LED가 안 켜지거나 흐리면 555 3번 전압이 낮은 것이다. 사람에게 연결하지 말고 멈춘다.

**5 V 선은 브레드보드에 하나도 남기지 않는다 (ESP32 핀은 3.3 V까지만 견딘다).**

## 조립 순서

1. 레일: ESP32 3V3·GND를 위 레일에, 59·60열에서 위아래 레일을 잇는다.
2. CH1의 TLC555와 AQY210EH를 가운데 홈에 걸쳐 꽂는다 (홈이 왼쪽).
3. 저항·커패시터 → 트랜지스터 → 보드 안 점퍼 순서.
4. ESP32 신호선(G32, G17, G16)을 꽂고 GUIDE.md 4.3 LED 검사.
5. 통과하면 CH2를 30열 오른쪽에 똑같이 복제 (G33, G19, G18).
5-1. 강도 사다리 (v2.2): 채널마다 AQY 2개(LA·LB), 470Ω·1kΩ, 330Ω 2개, 점퍼. ESP32 G23·G4(CH1), G13·G14(CH2). TENS 없이 `ladder_test.py`로 먼저 확인.
6. 마지막에 참가자 STOP·TENS 출력(주황). 실험자는 SPACE 키를 맡는다. 리드선 연결은 [output_wiring_simple.png](output_wiring_simple.png).
