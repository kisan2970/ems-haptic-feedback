# 브레드보드 꽂는 위치 목록 (830홀, 우노, 2채널 v2) — 간소화판 (키스위치·부저·실험자 E-STOP 생략)

그림: [breadboard_830_simple.png](breadboard_830_simple.png). 열 번호 1~63, 행 a~j. 위쪽 레일은 바깥쪽 빨강 줄이 +5V, 안쪽 파랑 줄이 GND. 아래쪽은 안쪽 파랑이 GND, 바깥쪽 빨강이 +5V.

레일 구멍은 5개씩 묶여 있고 7·13·19·25·31·37·43·49·55·61열 자리는 비어 있다.

## 공통

| 부품 | 위치 |
|---|---|
| 점퍼선 (위 + 레일 ↔ 아래 + 레일) | 위 + 레일 60열 ↔ 아래 + 레일 60열 |
| 점퍼선 (위 − 레일 ↔ 아래 − 레일) | 위 − 레일 59열 ↔ 아래 − 레일 59열 |
| IMU (GY-521) | 우노 3.3V → VCC, 우노 GND → GND, A5 → SCL, A4 → SDA. 시연 때는 긴 선으로 손등에 고정 |

## 조립 순서

1. 레일: 우노 5V·GND를 위 레일에, 59·60열에서 위아래 레일을 잇는다.
2. CH1의 TLC555와 AQY210EH를 가운데 홈에 걸쳐 꽂는다 (홈이 왼쪽).
3. 저항·커패시터 → 트랜지스터 → 보드 안 점퍼 순서.
4. 우노 신호선(D9, D4, D5)을 꽂고 GUIDE.md 4.3 LED 검사.
5. 통과하면 CH2를 30열 오른쪽에 똑같이 복제 (D10, D7, D6).
6. 마지막에 참가자 STOP·TENS 출력(주황). 실험자는 SPACE 키를 맡는다.
